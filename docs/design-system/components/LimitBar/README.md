Полоса лимита или бюджета: потрачено против лимита и метка того, где месяц сегодня.

- **Потребитель даёт** название, потрачено и лимит (суммы с сервера), долю `--w` (0–100 %), долю прошедшего месяца `--x`, состояние.
- **Состояния:** без класса — заливка `ink` и спокойная подпись; `is-near` от 80 % — `over-bar` и подпись `over`; `is-over` — полоса полная, подпись «… сверх лимита» цветом `over`.
- **Метка** `tick` — сегодняшний день месяца; под ней видно, идёт ли трата быстрее времени.
- **Подпись обязательна:** состояние не передаётся одним цветом.
- **Платформы:** одинаково.
