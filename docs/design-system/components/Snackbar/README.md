Сообщение после действия с возможностью его отменить: «Трата удалена · Отменить».

- **Разметка:** `ck-toast` с `role="status"`, `.msg`, одной кнопкой действия и `.count` (полоса отсчёта, видна только на iOS).
- **Когда:** после добавления, удаления, переноса — вместо вопроса «Вы уверены?». Действие ждёт 5 с и уходит раньше, если человек покидает экран (как отмена удаления в 1.x).
- **iOS:** тост `ink` с углом 16 над таб-баром, полоса отсчёта `inv-action` убывает 5 с.
- **Android:** снэкбар Material 3: угол `radius-snackbar`, высота от 48 px, над навигацией; FAB поднимается над ним. Полосы отсчёта нет.
- **Текст:** что произошло, в прошедшем времени, тем же словом, что на кнопке. Одно действие, словом «Отменить».
- **Нельзя:** два сообщения одновременно, сообщение об ошибке без способа исправить, сообщение без действия дольше 4 с.
