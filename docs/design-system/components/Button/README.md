Кнопка: одна главная красная на экран, остальные тональные или тихие.

- **Варианты:** `primary` — `seal`, одно главное действие экрана («Сохранить · 8 760,98 ₸», «Снять чек» в листе «＋»); `tonal` — `surface-2`, второстепенные действия; `quiet` — без фона, отмена и «Не сейчас»; `danger` — контур `error`, удаление и выход.
- **Размеры:** высота `tap-ios` на iOS и `tap-android` на Android, 40 px под мышью; `sm` — в карточках; `block` — во всю ширину в листах и формах.
- **Текст:** глагол того, что произойдёт; суммы — через `Money`. Пока идёт запрос — `disabled` и «Сохраняем…».
- **Отклик:** iOS — приглушение до 55 %, без волны; Android — слой состояния 8 % при наведении и 10 % при нажатии, волна от точки касания. Сжатие до 97 % на 90 мс — на обеих.
- **Нельзя:** две `primary` на экране, `primary` для удаления, кнопка из одного значка без `aria-label`.
