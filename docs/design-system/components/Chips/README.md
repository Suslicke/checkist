Чипы-фильтры и сегменты: выбор того, что показать, без перехода на другой экран.

- **Чипы** (`ck-chips` › `ck-chip` с `aria-pressed`) фильтруют список: категории, участники семьи, способ оплаты. Выбранный залит `ink`, текст `paper`: выбор — чернилами, действие — `seal`. Внутрь кладите `<svg class="ck-ic"><use href="#check"/></svg>`: на Android он виден у выбранного чипа.
- **Сегменты** (`ck-seg` › `button` с `aria-pressed`) переключают вид тех же данных: неделя, месяц, год. Не больше четырёх.
- **iOS:** чип — капсула 34 px; сегменты — дорожка `surface-2` с выпуклым выбранным сегментом.
- **Android:** чип — угол 8 px, высота 32 px, контур `ink-2`, у выбранного галочка; сегменты — общий контур-«таблетка» Material 3, у выбранного галочка и подложка.
- **Нельзя:** чип как кнопка действия, больше одного ряда сегментов.
