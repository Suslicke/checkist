Подтверждение необратимого действия: удалить чек вместе с фото, выйти из семьи, убрать человека.

- **Когда:** только если отменить потом нельзя. Удаление траты, перенос, правка — без вопроса, с отменой в `Snackbar`.
- **iOS — лист действий снизу:** `ck-dialog` › `.grp` (пояснение `.msg` и опасное действие `button.danger` полным названием «Удалить чек и фото») и отдельная `.grp.cancel` с «Отмена». Стекло `material`, отступ 8 px.
- **Android — диалог Material 3 по центру:** заголовок-вопрос `ck-heading` («Удалить чек и фото?»), `.msg`, справа `.acts`: «Отмена», затем опасное `danger` коротко («Удалить»). Закрывается системным «назад» как «Отмена».
- **Обе:** `role="alertdialog"`, фокус при открытии на «Отмена», текст объясняет последствия одной-двумя фразами.
- **Нельзя:** «Вы уверены?» без последствий, «Да / Нет» вместо глаголов, опасная кнопка цветом `seal`.
