Переключатель: настройка, которая действует сразу, без кнопки «Сохранить».

- **Разметка:** `<label class="ck-switch-row">Подпись<input class="ck-switch" type="checkbox" switch></label>`. Подпись — существительное или «Делать что»: «Скрывать суммы», «Напоминать о платежах».
- **iOS:** атрибут `switch` даёт системный переключатель Safari 17.4+ с `accent-color: var(--income)` и, по заметкам WebKit, тактильным откликом на iOS 18. Где его нет (на `<html>` не стоит `data-switch="native"`), класс рисует такой же вид 51 × 31: дорожка `track`, включённый — `income`, бегунок `on-seal`.
- **Android:** переключатель Material 3 52 × 32. Выключенный — контур `ink-2` и бегунок 16 px; включённый — дорожка `income`, бегунок 24 px с галочкой. При переключении — `navigator.vibrate(10)`.
- **Нельзя:** переключатель, которому нужно подтверждение; переключатель вместо выбора из двух равных вариантов (тогда `Chips` → сегменты).
