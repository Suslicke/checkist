Верхняя полоса экрана: где я, как вернуться и одно-два действия.

- **iOS, корень раздела:** большой заголовок `ck-title-large` в `ck-largetitle`; при прокрутке он сворачивается в `ck-topbar` с `.mid` по центру, полоса получает `is-scrolled` (стекло).
- **iOS, вложенный экран:** `.back` — шеврон и название экрана, куда вернёт («‹ Траты»), цвет `seal-ink`; `.act` — действие словом («Изменить»). С экрана «Домой» у Safari нет своей кнопки «назад», поэтому `.back` есть на каждом вложенном экране.
- **Android:** `ck-topbar` высотой `topbar-android`: `.icon` со стрелкой «←», `.mid` со стилем `ck-heading`, справа до двух `.icon`, остальное в «⋮». При прокрутке — `is-scrolled` (заливка `nav-android`, без тени). Системный «назад» делает `history.back()`, как стрелка.
- **«Назад» ведёт туда, откуда пришли** (`Link back` и `goBack` из 1.x), запасной адрес — раздел экрана.
- **Нельзя:** больше двух значков справа, заголовок по центру на Android, шеврон на Android и стрелку на iOS.
