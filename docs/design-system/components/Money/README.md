Сумма денег: целая часть, копейки только когда они есть, знак валюты после числа.

- **Потребитель даёт** строку суммы с сервера (точную, без округления) и код валюты. Разбиение на части делает `lib/money.ts` (`int`, `frac`, `sign`); сам компонент ничего не считает.
- **Разметка:** `<span class="ck-money ck-money-hero"><span class="i">312 418</span><span class="f">,40</span><span class="c">₸</span></span>`. Размер задаёт стиль текста: `ck-money-hero` (одно на экран), `ck-money-display`, `ck-title`, `ck-body`.
- **Модификаторы:** `is-in` — доход, со знаком «+»; `is-over` — сверх лимита, рядом слова «сверх лимита»; `is-hidden` — режим «Скрывать суммы»: размытие на экране и `role="img" aria-label="сумма скрыта"` для диктора.
- **Другая валюта:** сумма как есть и рядом `ck-twin` «≈ … ₸» в основной валюте.
- **Платформы:** одинаково на iOS и Android.
- **Нельзя:** округлять, писать «,00», складывать разные валюты, красить траты в красный, переносить сумму на две строки.
