Строка траты: плитка категории, место, откуда пришла трата, и сумма.

- **Потребитель даёт** место (или «Без места»), номер тона категории `ck-c1` … `ck-c6`, значок категории, источник и время, сумму через `Money`.
- **Источник** — значок и слово перед датой: «Фото» (`receipt`), «Выписка Kaspi Gold» (`card`), «Словами» (`insight`), «Вручную» (`pencil`). Средняя точка в подписи одна.
- **Сумма** справа цветом `ink`, никогда не красная. Название обрезается многоточием, сумма — никогда.
- **Загрузка** рисует ту же строку блоками `ck-sk` того же размера.
- Строки лежат в `ck-panel`; разделитель только между строками.
- **Платформы:** одинаково; на Android касание даёт слой состояния, на iOS — приглушение (см. `Button`). Смахивание влево удаляет с отменой в `Snackbar`.
