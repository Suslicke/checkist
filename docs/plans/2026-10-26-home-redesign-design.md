# Главная, раздел «Деньги» и нижнее меню — дизайн и контракт (2026-10-26)

Просьба человека: «сильно переработать интерфейс, что-то на Главную, в нижнее меню»; выбрано: герой — «Потрачено»
кольцом по категориям плюс «пульс месяца» (траты по дням), меню телефона «Главная · Траты · ＋ · Деньги · Ещё».
Макет (утверждён): `frontend/home-preview/index.html` — левая рамка «Главная», правая «Деньги». Цвета и размеры —
токены; новых анимаций нет; кольцо и столбики — свой SVG/дивы в `lib/charts` (без библиотек).

## Главная (`/`, `GET /api/dashboard/?month=`)
Порядок карточек на телефоне и в левой колонке компьютера (правая — лимиты и плитки, как в ПК-раскладке):
1. **Шапка**: «Октябрь» + две маленькие круглые кнопки ‹ › (смена месяца; стрелки «назад» нет), справа ✦ (чат,
   `/chat`) и аккаунт — ✦ в шапке на всех экранах (`HeaderSlot`/brand bar).
2. **Герой** (`dash-hero`): кольцо — `ring` в `lib/charts` (SVG, 132 px, толщина 14, сегменты = корневые
   категории `categories[]` по `spent` в основной валюте, цвет `categoryTone`; незалитая часть = остаток бюджета
   `budget.amount − spent`, без бюджета кольцо полное по категориям), в центре «Потрачено» / сумма / «N % бюджета»
   (без бюджета — «за месяц»); справа легенда ≤ 4 категорий + «ещё N» + строка «Остаток бюджета». Ниже **пульс**:
   `by_day[]` (новое поле) — столбик на каждый день месяца (`cat-1-tint`, с тратами `cat-1`, сегодня `--ck-accent`,
   будущие дни — `--ck-track` 3 px), пунктир среднего дня (`average_day`), подпись «1 окт · сегодня N · средний день
   X · 31». Строка итога: «из <бюджет> · ещё N дней · в день <allowance.per_day>» (без бюджета — «ещё N дней ·
   средний день X»). Переехало из прежнего героя и убрано: «на N % больше, чем в сентябре», полоса бюджета, абзац
   «Бюджет месяца минус …» (он остаётся только как `title`/диктор у «в день»).
3. **«Требует внимания»** (`attention[]`, новое поле, до 3 строк + `attention_more`): строки с `kind`
   `payment_due`|`payment_overdue`|`income_missing`|`limit_near`|`limit_over`|`plan_verdict`|`plans_question`,
   `title`, `meta`, `href`, `amount?`, `currency?`; порядок — просрочено, срок ≤ 2 дней, лимит > 100 %, доход
   (с 1-го по 10-е и доход месяца не внесён, а регулярный доход есть), лимит ≥ 80 %, вердикты ИИ `wait|drop` по
   открытым планам месяца, вопросы о прошлом месяце. Нет строк — карточки нет.
4. **Плитки** Платежи · Планы · Цели (`tiles`, новое поле: `payments {paid, total, left, currency, segments:[{paid}]}`,
   `plans` = нынешний `planned` (может быть null → плитка «Пока без планов»), `goals {count, share, saved, currency,
   top: [{name, share}]}`); касание → `/recurring`, `/planned`, `/goals`.
5. **«Сегодня и вчера»**: `recent[]` прежний (10 последних) — клиент показывает траты с `purchased_on` сегодня/вчера
   (при просмотре прошлого месяца — последние 3), пусто — «Сегодня трат нет» + «Все траты».
6. **Лимиты** компактно: имя, «N % · потрачено из лимита», полоса в цвете категории, сверх лимита — `--ck-over-*`;
   подкатегории с лимитом — вложенные, как сейчас, но без «Задать лимиты» в карточке, когда лимитов нет (тогда
   карточка — одна строка-ссылка).
Удалено с Главной: карточка «Загрузить чек / Добавить» (есть «＋»), отдельные карточки `IncomeSummary`,
`RecurringDue`, `PlannedCard` (их содержание — в «Требует внимания» и плитках; компоненты остаются для своих
экранов, `RecurringDue` — на `/recurring`).

Сервер: `by_day: [{day: "YYYY-MM-DD", spent}]` (все дни месяца, в основной валюте, траты по `purchased_on`,
скрытые/невидимые — как везде `visible_receipts_q`), `average_day` (сумма / прошедшие дни включая сегодня, для
прошлого месяца — / число дней), `attention`, `attention_more`, `tiles`. Число запросов постоянно. Старые поля не
меняются. Правило: строка «Требует внимания» — только из того, что сервер уже считает (`recurring.services.unpaid`
/ `month_view`, `incomes.services.month_income` + регулярный доход, `budget.dashboard` лимиты, `PlannedSpend.ai_*`).

## «Деньги» (`/money`, новый экран; `GET /api/money/?month=`)
Шапка «Деньги» + ✦ + аккаунт. Карточка месяца: `income`, `spent`, `set_aside` (взносы в цели за месяц) в основной
валюте, полоса потока `flow {spent, payments_ahead, plans_ahead, free}` (`free` = доход (или бюджет, если дохода
нет) − spent − неоплаченные платежи − открытые планы; < 0 — медный «перерасход»), подпись. Плитки 2 × 3
(`.money-hub`): Доходы (`income`, «за октябрь не внесён» при отсутствии), Платежи (`payments.left`, «N из M оплачено
· <ближайший> через K дней»), Планы (`plans.left`, «ждём · N без срока»), Цели (`goals.share %`, две верхние),
Статистика (мини-столбики `months[]` — 6 месяцев трат в основной валюте, текущий выделен, подпись «октябрь пока
ниже/выше среднего»), Разбор (последний `review` прошлого месяца: месяц, изменение к прошлому, число советов; нет —
«Запросить разбор»). Карточка «Чат с ИИ» — последняя беседа (`GET /api/insights/threads/` клиентом) + «Все
беседы». Касания ведут на `/incomes`, `/recurring`, `/planned`, `/goals`, `/stats` (запомненная вкладка),
`/review`, `/chat`. Сервер отдаёт всё одним ответом, число запросов постоянно.

## Меню
Телефон: «Главная · Траты · ＋ · Деньги · Ещё» (`primary`: `stats` → `money`, значок `coins`/существующий);
`groups` → раздел «Деньги» в «Ещё» убирается (он теперь экран `/money`), в «Ещё» остаются «Данные» и
«Настройки»; `/more` без раздела «Деньги». Компьютер (шапка): «Главная · Траты · Деньги · Статистика · Данные ▾ ·
Настройки ▾» + ✦ рядом с именем; `/money` — тот же экран в две колонки (сводка и чат слева 2fr, плитки справа
3fr). Прогрев (`warm-up.ts`) — добавить `/api/money/`. `sw.js` — `money/` как `api` (кэшируемый GET).
Не делается: смена порядка карточек человеком, виджеты, push.
