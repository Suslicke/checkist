# Чекист 2.0: переход всего клиента на новую дизайн-систему (2026-11-20, ветка `feature/design-2`)

Просьба человека: «Completly rewrite application to new design system, until it will be done, don't stop. We should
rewrite ALL APLICATION». Спецификация — `docs/design-system/` (README.md — бренд, platforms.md — iOS и Android,
tokens.json — значения, components/*/README.md и preview.html — компоненты, components/bundle.css — образец CSS,
direction.html — страница направления с Главной, чеком, месяцем и листом «＋»). Этот файл — контракт для всех, кто
переписывает экраны: имена, общие части, кто чем владеет и как проверять.

Поведение, данные, адреса, запросы к API и доступность не меняются: меняется вид и грамматика платформ. Сервер не
меняется (кроме того, что прямо названо ниже).

## 2. Платформа, тема, приватность

- `<html data-platform="ios|android">` ставит встроенный скрипт `index.html` до отрисовки (platforms.md), компьютер —
  `android`. Для проверки и снимков: `localStorage['checkist.platform'] = 'ios' | 'android'` важнее определения.
  Код: `frontend/src/theme/platform.ts` — `platform()`, `usePlatform()`. CSS: `:root[data-platform="ios"] …`.
- `data-switch="native"` — iOS с `<input switch>`.
- Тема — прежняя (`checkist.theme`, `data-theme="light"`), `theme-color` по теме.
- Приватность: `localStorage['checkist.privacy'] = '1'` → `<html data-privacy>`; все `.ck-money` размываются (не
  текст, а `filter: blur` + `user-select: none`; диктор читает «скрыто»). Код: `theme/privacy.ts` (`usePrivacy`,
  `togglePrivacy`), значок-кнопка «глаз» `components/PrivacyToggle.tsx`.

Правило выбора: одно главное действие экрана — `seal`. Выбор — `ink`. Текущий раздел — `seal-ink`. Ассистент и вехи —
`gold`/`gold-ink`. Траты — `ink`, не красным. Доход — `income` со знаком «+». От 80 % лимита — `over` со словами.
Ошибка — `error` со словами.

## 4. Движение

Разрешено (всё — только под `prefers-reduced-motion: no-preference`): нажатие 90 мс; смена состояния 180 мс; счёт
главного числа 420 мс; переход экрана View Transitions (iOS 350 мс, Android 300 мс); лист 360 мс; печать чека 1,3 с и
штамп 0,5 с — один раз после распознавания; отсчёт отмены 5 с; из 1.x — смена месяца, полоса сети, пульс скелета.
Других анимаций нет.

## 6. Правила CSS экранов

- Цвет — только `var(--ck-<имя 2.0>)`; hex, rgb и имена 1.x не писать. `color-mix()` поверх токенов можно.
- `font-size` — только `var(--ck-text-*)` 2.0 или классы стилей текста.
- Отступы и углы — токенами. Цель касания — не меньше `var(--ck-tap)`.
- Видимые суммы — `<Money>`; в фразах и `aria-label` — `formatMoney`.
- Пороги прежние: телефон `max-width: 540px`, компьютер `min-width: 960px` (`theme/desktop.css` — раскладка
  компьютера сохраняется, правила компьютера только там; владелец каждого экрана правит свои строки в нём).
- `App.css`/`shell.css` идут после CSS экранов: общие правила состояний в них — через `:where()`.

## 7. Проверка

- Свои тесты: `cd frontend && npx vitest run src/features/<папка>`; `npx tsc -b`; `npx eslint <папки> --max-warnings=0`.
  Разметочные тесты своей папки правятся вместе с намеренным изменением разметки; тесты поведения и доступности не
  ослабляются.
- Вид: локальный стенд (раздел 8) — 390 px и 1280 px, обе темы, обе платформы.
- Не коммитить, не запускать `npm run build` (общий `dist`) — это делает координатор.
